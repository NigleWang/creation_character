# Kai 穿搭提示词 — 藏青飞行员夹克 Look

来源：ceroestresindumentaria 的 outfit board（画面中央是上身效果，左右是同套单品与配饰平铺）。

这张图只锁定**衣橱**。不要把它当成构图、姿态或场景参考，也不要让成图里出现平铺衣服、重复单品或 Instagram 界面。

人物身份以 `characters/kai/bible.md` 和 `characters/kai/references/face_01.jpeg` 为准。服装以这张 outfit board 为准。两者冲突时：脸、发型、体型跟 Kai；颜色、图案、材质、版型跟服装图。

## Outfit Bible

| 部位 | 锁定 |
|------|------|
| 外套 | 深藏青飞行员夹克（bomber）。金属拉链**敞开**，露出衬衫。罗纹立领、罗纹袖口、罗纹下摆。哑光羊毛或棉混纺，不是尼龙亮面，不是皮衣，不是西装外套。 |
| 上衣 | 比夹克更深的海军蓝长袖纽扣衬衫。白底大朵抽象花卉（山茶 / 白花形），花朵要能认出来。领子露在夹克领之上，领口第一颗扣子解开，其余扣好，下摆塞进裤子。不是纯色，不是条纹，不是小碎花。 |
| 下装 | 黑色直筒西裤，平前襟，裤线干净，裤脚轻搭鞋面。不是牛仔裤，不是工装裤。 |
| 腰带 | 黑色皮带，银色方扣，穿在裤袢里。 |
| 鞋 | 黑色抛光皮革牛津鞋，系带、薄底、圆头。不是运动鞋，不是靴子。 |
| 手表 | 黑色表盘、黑色皮带、银色表壳的圆表，戴在**左手腕**。 |
| 手链 | 黑色皮带、一排小银钉的手链，戴在**右手腕**。 |
| 墨镜 | 黑色板材、略圆的方框。**不戴在脸上**，挂在敞开的衬衫门襟上。眼睛、笑纹、胡茬必须露出来。 |
| 钱包 | 棕色皮革对折钱包，放在右侧后袋或夹克内袋，最多露出一角皮边。不要拿在手里当商品展示。 |

配饰这样分配，是因为脸的辨认优先于「全部戴上」。墨镜盖住眼睛会改掉 Kai。

## 视频提示词怎么写

穿衣视频是**图生视频**。第一帧必须是 Kai 已经穿好这套衣服的定妆静帧。平铺图只在出定妆图时当衣橱参考，不要上传到 Gemini 当视频首帧。

1. 用上面的「定妆图」提示词出一张全身静帧。参考图是 Kai 脸图，再加 outfit board。
2. 静帧里的脸、花衬衫、敞开的藏青夹克、黑西裤和配饰都对上之后，再写视频词。
3. 打开 Gemini，**只上传这张定妆静帧**，时长 10 秒，竖屏 3:4，粘贴下面的英文块。

视频词只加动作、镜头和台词。衣服已经在身上，不要再写穿上、扣上、换装。手只碰到夹克袖口或拉链边，让表和手链露出来。墨镜一直挂在门襟上。

台词是日语假名。第一条在 2.0 秒开口。
