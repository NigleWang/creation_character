写好这类账号的文案，核心是：**短、有画面感、带一点情绪，让人觉得像在看他们的生活片段**。

### 文案基本公式（推荐）

**1. 开头抛一个小场景/情绪**（1句话）  
**2. 加一个细节或互动**（1-2句）  
**3. 结尾轻轻收住，或留一个小问题**（可选）

控制在 **30-80字** 左右最合适，太长没人看。

---

### 单人照文案模板 & 示例

**Kai（攻）单人：**
- 模板：气场/动作 + 小情绪
- 示例：
  - 「今天的Kai有点懒，外套都懒得拉链。」
  - 「侧颜杀伤力太强了，看久了会心跳加速。」
  - 「刚运动完的Kai，耳尖还有点红。」
  - 「把头发拨上去的时候，下颌线更明显了。」

**Teo（受）单人：**
- 模板：软感/表情 + 小心思
- 示例：
  - 「Teo今天好像有点困，眼睛都是水润的。」
  - 「低头玩手机的样子，莫名很想揉他头发。」
  - 「穿这件衣服的Teo，看起来特别好抱。」
  - 「悄悄看镜头的瞬间，耳尖红了。」

---

### 双人合照文案模板 & 示例

**模板：一个小互动 + 情绪**
- 示例：
  - 「Kai把外套披到Teo肩上，Teo嘴上说着不要，身体却没躲开。」
  - 「走路的时候，Kai的手自然地搭在Teo后腰。」
  - 「Teo靠在Kai肩膀上睡着了，Kai连呼吸都放轻了。」
  - 「两个人并排坐着，谁都没说话，但空气很安静很舒服。」
  - 「Kai低头说了什么，Teo耳尖瞬间红了。」

---

### 进阶小技巧

1. **多用“今天”“刚才”“刚刚”**，增加真实感。
2. **少用夸张形容词**（比如“绝美”“神颜”），用细节更打动人。
3. **适当留白**，不要把所有情绪都写满，让粉丝自己脑补。
4. **结尾可加互动**（提高评论）：
   - 「更喜欢今天的Kai还是Teo？」
   - 「猜猜Kai刚才说了什么？」
   - 「这种安静的相处，喜欢吗？」

### 完整笔记示例

标题：今天的侧颜有点犯规  
正文：  
刚洗完头的Kai，头发还是湿的。  
随手拨上去的时候，下颌线突然变得很锋利。  
看久了会有点移不开眼。

**合照：**
标题：外套还是他的比较暖  
正文：  
出门的时候Teo说有点冷。  
Kai直接把自己的外套披过去，还顺手把拉链拉上了。  
Teo没说话，只是把脸往领口里埋了埋。

好文案 = 一个小场景 + 一个细节 + 一点点情绪。
