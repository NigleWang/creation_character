# Generate Single Character Post

**Trigger:** `@virtual-couple` + scene upload + one of `@Teo` / `@Kai`

## Steps

1. Load only mentioned character from character-registry
2. Scene analyzer with `subjects.count: 1`
3. Generate with single character reference only
4. QC and deliver

## Example

```text
@virtual-couple @Teo
[上传场景图]
Teo单人日常，小红书
```
