# Douyin Caption — 猛男日语教学

账号：**猛男日语教学**。用 Tagame（办公室肌肉上司）的日语台词当教材：观众来看猛男，走的时候学会三句。

本 skill **只写文案**。不要调用 `GenerateImage`。不要走 Teo/Kai 小红书文案。

| Pipeline | Input | Output |
|----------|--------|--------|
| `tagame-anime` Turn C2 | 用户已选的 3 句假名台词 | **一条**抖音标题+文案+标签 |
| **本 skill 单独** | 成图 / 视频词 JSON + 抖音文案 | 复制即发 |

---

## When to run

**必跑：** `tagame-anime` Turn C2 写出 10s 提示词之后（台词已锁定）。

**也跑：** 用户说 抖音文案 / 抖音标题 / 抖音标签 / 抖音发布 / 猛男日语教学 / caption。

不要在 Turn A 场景卡或 Turn C1 台词选项阶段写发布文案（句子还没选定）。

| 项 | 规则 |
|----|------|
| 账号名 | 猛男日语教学 |
| 人设 | 动漫肌肉上司教你日语口语，不是语法课老师 |

## Workflow (one shot)

1. 锁定三句台词：优先 `outputs/drafts/tagame_video_<task_id>.json` 的 `dialogue`；否则读用户选定的 C1 选项；再否则读成图附带的视频词。
2. 每句标：假名、中文、**一个**语法/语气钩（`だけ` `んだぞ` `おいで` `～てみたい` 等）。
3. 写 **1 个标题 + 1 段正文 + 6–10 标签**。标题要能当封面口播钩子。
4. 另给 **2 个备选标题**（fence 外）。
5. 保存：
   - `outputs/drafts/douyin_<task_id>.json`
   - `outputs/drafts/douyin_<task_id>.txt`（仅复制块）
6. 按模板回复。复制块放进 **一个** `text` fence。

用户已给 标题口吻 / 不要提问 / 更教学 / 更撩：照做。

## 文案公式

```
标题：日语句（或中文钩）+ 教学钩（什么意思 / 怎么说 / 跟读）
正文：
  1. 一句账号身份或场景（猛男上司 / 加班走廊…）
  2. 今日三句：假名 + 中文 + 半句用法
  3. 结尾跟读或评论区造句（用本条语法点）
```

| 项 | 规则 |
|----|------|
| 标题 | **≤22 字**，必须能停住刷：带一句日语 **或**「这句日语什么意思」类钩。不要「1/n」、不要「AI视频」 |
| 正文 | **80–180 字**。三句都要教到，但每句只讲 **一个**点 |
| 标签 | **6–10 个**，放正文最后；**教学词 + 猛男/二次元词各一半** |

### 标题句式（每条换着写，不要连用同一句）

- `这句「{最短日语}」什么意思`
- `{中文意思}，日语怎么说`
- `猛男上司教你：{语法点}`
- `跟读｜{假名短句}`
- `日语口语｜{中文钩}`

优先用 **第三句或第一句** 里最好记的词（`おまえだけ` `おいで` `あつい`）。

### 正文要点

1. 开头 1 句点明「日语口语 + 眼前这个人」，不要自我介绍账号名堆砌。
2. 三句用 ①②③，假名与中文分行或用 `＝`。
3. 用法只写半句人话，例如：「`だけ`＝只、仅仅」「`んだぞ`＝带点强硬的解释」。
4. 结尾要互动：跟读 / 用这个词回一句 / 猜下一句。提高评论。
5. 少用「绝美」「神颜」。可以写热、低音、衬衫、加班——服务记忆单词。

### 禁止

- `#TeoKai` `#虚拟情侣` `#AI` `#换脸`
- 把三句日语只翻译、不教用法（这就不是教学号）
- 三句全写成「邀请→热→占有」解说而没有语法点
- 英文标题、日语汉字（跟视频一致：假名；中文解释里可写汉字词性）

---

## 标签

每条 **6–10 个**。**教学池 + 人设池各一半**（8 个 = 4+4）。不要只打自建词，也不要堆无关热搜。

### 自建 / 账号（约一半，必带前两个）

每条必带：`#猛男日语教学` `#日语教学`

再从这里补满一半：`#跟着猛男学日语` `#日语口语` `#今日日语`

### 大池子（约一半，按内容选）

教学发现：`#日语学习` `#学日语` `#日语入门` `#日语单词` `#日语发音`

人设发现：`#二次元` `#动漫` `#肌肉男` `#猛男`

| 画面/台词 | 再加（0–2 个） |
|-----------|----------------|
| 办公室、加班、衬衫 | `#办公室` |
| 健身、更衣室、汗 | `#健身` |
| 雨、车、酒店 | 对应场景词 **最多 1 个** |

对不上的不要硬加。禁止 `#BL` `#AI` `#虚拟男友`。

### 推荐搭配

办公室三句：

```
#猛男日语教学 #日语教学 #日语口语 #今日日语 #日语学习 #学日语 #二次元 #肌肉男
```

更衣室/汗：

```
#猛男日语教学 #日语教学 #跟着猛男学日语 #日语口语 #日语学习 #健身 #肌肉男 #猛男
```
