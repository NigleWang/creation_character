# douyin-caption examples

账号始终是 **猛男日语教学**。

## 1) 加班责问三句

**台词：**  
こんなじかんまで、のこってたのか / おまえのせいだ、かえれなくなる / ほら、こっちをみろ

```text
这句「おまえのせいだ」什么意思

加班走廊，上司压低声音教三句口语。
① こんなじかんまで、のこってたのか
＝ 都这时候了，你还留着？
（こんなじかん＝这种点了）
② おまえのせいだ、かえれなくなる
＝ 都是你的错，我回不去了
（せいだ＝归咎于）
③ ほら、こっちをみろ
＝ 喂，看这边
（みろ＝看，命令形）
评论区造句：用「せいだ」回我一句。

#猛男日语教学 #日语教学 #日语口语 #今日日语 #日语学习 #学日语 #二次元 #肌肉男
```

备选标题：1) 猛男上司教你：せいだ  2) 跟读｜こっちをみろ

## 2) 经典邀请占有（当用户选了 A）

仍要教语法，不要只写「他在调情」。

```text
「さわってみたくないか」怎么说

白衬衫上司，三句把「要不要试试」说完。
① このむね、さわってみたくないか？
＝ 这胸膛，不想摸摸看吗？
（～てみたくないか＝要不要试试）
② スーツごしでもわかるくらい、あついんだぞ
＝ 隔着西装也能感觉到有多热
（ごし＝隔着；んだぞ＝强硬解释）
③ おまえだけのものだ
＝ 只属于你
（だけ＝只、仅仅）
跟着念第三句，评论区打「だけ」。

#猛男日语教学 #日语教学 #跟着猛男学日语 #日语口语 #日语学习 #学日语 #二次元 #肌肉男
```

## 3) 教学向 J 弧

```text
猛男上司教你：あつい

他问你「热」日语怎么说，顺便不让你走神。
① ちょっと、きいてくれ
＝ 听我说一句
（～てくれ＝帮我做）
② あつい、っていみ、わかるか
＝ 「热」是什么意思，懂吗
（って＝引用）
③ きょうのたんご、おまえだけだ
＝ 今天的单词：只属于你
（たんご＝单词；だけ＝只）
把「あつい」跟读三遍。

#猛男日语教学 #日语教学 #日语单词 #日语口语 #日语学习 #日语入门 #二次元 #猛男
```
