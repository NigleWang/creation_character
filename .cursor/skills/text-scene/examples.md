# text-scene examples

## Brief → filled card

**User:** `周末早上两个人在厨房`

```text
✅ 场景已按人设补全（构图/动作如下，可改）

【谁】双人 Teo左 Kai右
【时间地点】周末早晨 · 家里厨房
【构图】3:4 中景，略侧窗光
【动作】Teo：靠料理台，看向 Kai，手握杯子 ｜ Kai：站在灶边，身体微侧向 Teo，在煎或煮
【服装】Teo：眉线眼镜，浅色家居衬衫 ｜ Kai：无眼镜，深色 T 或卷袖衬衫
【光与道具】窗光；马克杯、平底锅，不要品牌字
【人设】Kai 动手，Teo 安静看着他

快捷：「生成」
⏸️ 请确认后再出图。
```

**User:** `Teo交图前在工作室`

```text
【谁】仅 Teo
【时间地点】傍晚 · 室内设计小工作室
【动作】坐在木桌前看样品，或对着软木板发呆
【服装】米白亚麻卷袖 + 眉线眼镜（人设锁定）
【不要】Kai、格子间双屏、把 Teo 画壮
```
